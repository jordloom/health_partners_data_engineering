# health_partners_data_engineering

## CMS Hospital Datasets Downloader
This script retrieves datasets from the CMS provider data API, filters them by the "Hospitals" theme, and processes each dataset by downloading it, cleaning the column names (converting to snake_case), and saving it as a CSV file. The script is designed to run daily and only downloads files that have been modified since the previous run.

## Requirements
- Python 3.7+
- See requirements.txt for required packages:
```
pandas
requests
```

Install Dependencies with:
```
pip install -r requirements.txt
```

## Usage
 1. Clone or download this repository.
 2. Install dependencies as above.
 3. Run the script:
 ```
 python firstAttempt.py
 ```
 4. Processed CSV files will be saved in the hospital_datasets directory.
